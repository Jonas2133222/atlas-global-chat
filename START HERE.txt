ATLAS — LIVE GLOBAL CHAT EDITION

WINDOWS ONE-CLICK SETUP
1. Extract the entire ZIP into a normal folder (do not run it inside the ZIP).
2. Double-click OPEN_ATLAS.cmd. It opens ATLAS at http://127.0.0.1:8765/
3. On first launch ATLAS installs the original genuine 8K globe textures, when the
   download is available. This preserves the maximum-quality visual experience.
   If a download fails, it uses the existing 4K globe as a fallback.
4. If you do not already have Node.js, the launcher also downloads the official
   portable Node.js runtime into .atlas-runtime. No npm or account needed.
5. Keep the full folder together. You may open the address in multiple browser tabs
   on your computer to verify live messages appear instantly.
6. For faster startup without the first-time 8K download, right-click
   START_ATLAS_LIVE.ps1 and choose 'Run with PowerShell'.

CHAT RULES
- Real messages, instantly shared among all connected visitors of the same server.
- Global / region / city rooms; choose a nickname and location in the website.
- 1-second per-user cooldown, enforced by the server (not just the button).
- Mild swearing is allowed, maximum TWO swear words per message.
- Slurs are rejected, including many disguised spellings; also checked in nicknames.
- Maximum 280 characters per message. Message reporting is included.
- Local messages are saved in chat-data/messages.jsonl. Reports in reports.jsonl.
- Chat is moderated by automatic filters, not monitored by a human. Filters are imperfect.

IMPORTANT: OTHER PEOPLE ON THE INTERNET
The one-click program runs a chat server on YOUR computer. Users on another computer
will not share that chat until you host the server publicly. Publishing just the HTML
file on a static host (e.g. GitHub Pages) does NOT work for live chat.

Public hosting: Put the contents of this folder at the root of a GitHub repository,
then create a Node web service on Render (or similar). Build command can be empty;
start command: node server.js. The included render.yaml is an optional Render Blueprint.
The hosting provider needs an active Node web service and must allow SSE.
The free Render service has cold starts, and its filesystem is NOT persistent on
redeploy/restart; for reliable permanent public message history, add durable storage.
Use only a single server instance without a shared DB; this built-in chat server keeps
live room state per process. On public hosting enable abuse monitoring and a privacy policy.

LOCAL TROUBLESHOOTING
- Do not double-click ATLAS Global.html directly; file:// cannot access chat endpoints.
- If the chat reads offline, open http://127.0.0.1:8765/api/health to check the server.
- If port 8765 is already used, close the conflicting service before launching.
- Chat logs are written inside the chat-data folder. Do not publish them to GitHub.
- The portable runtime is official Node.js and requires Internet only to download once.
