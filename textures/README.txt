Optional real 8K globe textures (Solar System Scope / CC BY 4.0):

Render will TRY to download these 3 files at build time automatically.
If the build reports download failures, on your own PC run OPEN_ATLAS.cmd
and find the JPEG files in "8K ASSETS". Copy them into this textures/
folder (at the REPOSITORY ROOT) and commit/upload them to GitHub:
  8k_earth_daymap.jpg    8192x4096
  8k_earth_nightmap.jpg  8192x4096
  8k_earth_clouds.jpg    8192x4096

If they exist here they will not be downloaded again.
Check public URL /api/texture-status; it must show available:true.
