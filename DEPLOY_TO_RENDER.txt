ATLAS — ULTRA 8K + PERFORMANCE — UPDATE EXISTING RENDER SITE

1) Extract ATLAS_RENDER_8K_PERFORMANCE.zip.
2) Open your GitHub repo (atlas-global-chat) -> Add file -> Upload files.
   Upload all of the updated contents (files and folders) to the ROOT.
   GitHub will ask to replace existing files; commit the changes.
   IMPORTANT: include "scripts/fetch-textures.js" and "textures/README.txt".
3) On Render, keep your EXISTING Web Service (no need to create a second one).
   Leave Build Command: npm install
   Leave Start Command: node server.js
   npm install automatically runs the optional 8K downloader.
   The site will auto-redeploy if auto-deploy is enabled. Otherwise use
   Manual Deploy -> Deploy latest commit.
4) After Live, open https://YOUR-SERVICE.onrender.com/api/texture-status
   If it reports {"available":true,"missing":[]}, Ultra 8K works.
   If it reports available:false, the build download failed. See step 5.
5) FALLBACK (guaranteed if your local 8K installer succeeded):
   On your Windows computer run OPEN_ATLAS.cmd once to fetch 8K textures.
   Find the 3 files in "8K ASSETS" in the extracted ATLAS folder.
   Upload those same 3 .jpg files to your GitHub repository's "textures" folder:
      textures/8k_earth_daymap.jpg
      textures/8k_earth_nightmap.jpg
      textures/8k_earth_clouds.jpg
   Commit and redeploy. Check /api/texture-status again.

GRAPHICS MODES under the globe:
- Performance: 30 FPS target, 1x pixel ratio, fewer animation effects
- Balanced (default): 45 FPS target, 1.5x pixel ratio, embedded high-quality maps
- Ultra 8K: 60 FPS target, up to 2x pixel ratio, genuine 8192x4096 maps
Quality settings are saved in your browser.
The server's 1-second chat cooldown and slur filters remain unchanged.

Technical notes: 8K textures are large, GPU memory-intensive and load on demand.
Users who select Ultra may experience a download delay. If server assets or
hardware are unsupported, the site switches back to Balanced rather than
falsely claiming 8K is active. Render Free may sleep when idle, and chat
history remains temporary after restarts.
